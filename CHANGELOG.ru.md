# Журнал изменений

*English version: [CHANGELOG.md](CHANGELOG.md).*

Значимые изменения photocat. Формат — [Keep a Changelog](https://keepachangelog.com/1.1.0/), версии —
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

**Как этот файл ведётся** (`AGENTS.md`, §6). Каждый коммит, который меняет то, что видит владелец,
что делает команда или что появляется на диске, в том же коммите добавляет одну строку в
`## [Unreleased]` — короткую фразу, а не рассказ — и повторяет её в `CHANGELOG.ru.md`. Метка в
квадратных скобках (`[M26.14]`) указывает на запись в `plan/STATUS.md`, где лежат числа, замеры и
приёмка: журнал — это история, которую читает человек, а журнал статуса — запись, нужная
сопровождающему. Релиз забирает раздел `[Unreleased]`, получает версию и дату, поднимает `version` в
`Cargo.toml` и начинает новый пустой `[Unreleased]`.

## [Unreleased]

### Добавлено

- Этот журнал и правило, которое его ведёт — `AGENTS.md` §6, `plan/I18N.md` [M26.15].
- Страница лиц держит пороги за одним переключателем «Настройка», который показывает значения и
  считает, что предложат ползунки сопоставления, ещё до прохода [M26.16].
- Автоматические сопоставления лиц ждут в карантине, пока владелец их не подтвердит: «Карантин · N»
  в списке групп, «Подтвердить все» и `faces --quarantine` / `confirm` / `reject` [M26.17].
- Знак: логотип-«кото-диафрагма» и его локап в `assets/`, и окно носит иконку — знак 256 px на
  плитке, вшитый в бинарник, плюс файлы 32/64/128 px для упаковки [M26.19].
- Знак и локап в SVG с цветами в переменных CSS (`photocat-mark`, `photocat-paper`, `photocat-word`,
  `photocat-band`), из которых `assets/render.sh` делает все PNG, а README берёт локап под тему
  читателя [M26.21].
- Локап по новой раскладке владельца: знак приложения рядом со словом, 800×220 — ровно тот размер,
  в котором его показывает README, — чернила обрамлены равным воздухом и ничего не обрезано [M26.22].
- Снимки всех экранов на английском и русском и галерея в `docs/SCREENSHOTS.md` и
  `docs/SCREENSHOTS.ru.md`.
- Социальное превью 1280×640: локап на своей плите в `assets/photocat-social.svg`, из которого
  `assets/render.sh` делает PNG для *Settings → General → Social preview* — та карточка, в которую
  разворачивается ссылка на репозиторий в Telegram, Slack, Discord, Reddit и X.
- Страница для GitHub Pages: `docs/index.md` и `docs/index.ru.md` — единственные два файла в `docs/`
  с front matter, поэтому Jekyll рендерит только их; на них сказано, что это за проект, словами, по
  которым его ищут, а все документы даны ссылками на их GitHub URL, а не второй копией, которая
  разошлась бы с первой (`docs/_config.yml`).

### Изменено

- Верхняя полоса несёт сам логотип, покрашенный акцентом темы — `#b45309` в светлой, — вместо
  нарисованного значка фото-библиотеки [M26.20].
- Автоматическое сопоставление больше не входит в названную группу само: шаг предлагает лицо, а
  подтверждение или отказ — решение владельца [M26.17].
- Настройки дублей ушли из левой панели на страницу, которой принадлежат группы: порог, «Найти
  группы», сводка и план теперь стоят над карточками [M26.18].
- README и метаданные пакета называют проект словами, по которым его ищут: фотокаталог,
  каталогизатор фотографий, photocatalog, — со своим разделом ключевых слов.

### Исправлено

- Кнопка «оставить» у дубля следует за своим словом на обоих языках, поэтому «оставить»
  остаётся одной строкой, а цифры справа в строке списка больше не заезжают под неё [M26.20].
- Заголовок экрана «Корзина» считает файлы в корзине, а не показывает «файлов 0, 0 Б».
- Заголовок дублей и строка статуса считают группы с правильным числом: «1 группа», а не «1 групп».

### Удалено

- «Отделить сопоставленные автоматически» и пометка `auto`: само в группу больше ничего не входит
  [M26.17].

## [0.1.0] — первая линия разработки, 2026-11-22 … 2026-11-27 (ещё не выпущена)

### Добавлено

- Индексация папок: обход `walkdir` в параллель, `sha256`, 64-битный dHash, дата, GPS и камера из
  EXIF, превью 320 px в кеше — в папку архива не пишется ничего [M1].
- Видео индексируются с кадром-обложкой, dHash, длительностью и разрешением через `ffmpeg` и
  `ffprobe`; обе программы необязательны, и всё остальное работает без них [M4].
- Точные и похожие дубли: `sha256` для точных, dHash с порогом Хэмминга (по умолчанию 6 из 64) для
  похожих, решения «оставить» / «лишнее» в БД и CSV-план на просмотр [M2, M5].
- Раскладка по датам: по умолчанию только план, и лишь с `--apply` — хардлинки, копии или симлинки
  по датам [M3].
- Альбомы как дерево с плотным порядком файлов, только в БД, и экспорт альбома нумерованными копиями
  на диск (`{n}_{orig}`, сначала план) [M19, M20].
- Родное окно на egui: сетка превью с заголовками месяцев, календарь, дубли, альбомы, лица, корзина,
  целостность и диалог настроек [M13, M16, M17, M22].
- Выбор нескольких плиток через `Shift`+клик и плавающая панель выбора [M18].
- Полноэкранный просмотрщик с масштабом, панорамированием, перелистыванием и серией дня
  [M13c, M13d, M22.7].
- Встроенный проигрыватель видео — H.264, HEVC Main, AAC, MJPEG и звук PCM, три потока, без внешних
  программ; кодек вне области поддержки получает отказ с причиной, а внешний проигрыватель
  предлагается только по явному нажатию [M14, M26.12].
- CLIP-теги и смысловой поиск, локально после одной загрузки с согласия: каталог моделей (две CLIP
  ViT-B/32, SigLIP base 224, SigLIP 2 base 224 multilingual), словарь тегов на каждую модель в БД,
  процентный порог на каждый тег и явное состояние «не уверен» [M7, M12, M15, M15.4, M15.6].
- Размеченная проверка тегов (`eval`): воспроизводимая выборка, `labels.csv`, контактные листы и
  точность top-1 / top-3 и уверенных тегов [M15.7].
- Распознавание текста через `tesseract` (необязателен) и поиск по распознанному тексту [M8].
- Люди: детекция и эмбеддинги SCRFD и ArcFace, группы лиц, имена, которые закрепляют группу,
  отделение лица, отделение отмеченных чужих сразу, и автоматическое сопоставление свободного лица с
  уже названным человеком при заданной близости и отрыве от следующего [M6, M26.10, M26.11].
- Целостность: сравнение двух копий архива, манифест `sha256sum`, проверка папки по нему, экран в
  окне и напоминание, которое само проверку не запускает [M9, M10].
- Поиск похожих кадров, который остаётся быстрым и выше 20 тысяч фото [M11].
- Корзина приложения: файл помечается в БД и остаётся нетронутым на диске; «Очистить корзину»
  переносит его в системную корзину после подтверждения, а плитка возвращается одним круглым
  значком [M22.27].
- Интерфейс говорит по-английски и по-русски: английский исходник идёт через `i18n::t`, русский
  текст живёт в таблице `PAIRS`, язык выбирается в настройках и определяется по локали системы при
  первом запуске; отчёты CLI следуют той же настройке [M21, M23].
- Две темы — тёмная, светлая и «как в системе» — из одной палитры токенов, с контрастом, который
  держит тест; светлый акцент — `#b45309` [M22.1, M22.11].
- Календарь в четырёх слоях: годы, месяцы, недели и дни, и под плитками каждого слоя — фото периода
  [M22.5, M25.10, M25.11, M25.12].
- Сборка для Windows: кросс-сборка MSVC из Linux, VC++ runtime и DirectML в папке, и выбор папки с
  кнопками дисков для диска Windows [M24.4].
- «Найти программы»: одно нажатие ищет `ffmpeg`, `ffprobe` и `tesseract` в `PATH` и в обычных местах
  системы, записывает только ту программу, которая запускается, и говорит, зачем каждая [M26.3].
- Значок предупреждения об ограниченной возможности с командой установки под эту ОС для копирования —
  ничего не устанавливается и не открывается браузер [M26.2].
- Каталоги: несколько корней, каждый выключается без потери своих строк, каждый выбирает, какие
  дорогие проходы по нему идут (лица, CLIP-теги, текст), и подтверждённое «забыть» только для
  производных строк [M26.1, M26.9]. Рабочий каталог — одна капсула со своим меню [M26.7].
- «Сжать» для файла БД: `VACUUM` SQLite за «Настройки → Хранилище», с размером файла и долей
  свободного места до нажатия [M26.8].

### Изменено

- Каждый экран перестроен по макетам владельца (`docs/references/mockups/`, `plan/M22-ui-spec.md`):
  одна рамка карточки, одна акцентная кнопка на экран, значок на каждой кнопке действия, числа в
  моно-шрифте [M22.x].
- Экран «Лица»: список групп переехал в правую панель, значок группы — лучшее лицо в ней [M22.26], а
  его настройки — модель, лицензия, согласие и загрузка, три порога и два прохода — ушли из диалога
  настроек на сам экран [M26.5], а затем из левой панели в верх его собственной страницы [M26.14].
- Левая панель стала картой приложения: сводка уехала в строку состояния [M25.5], порог тегов
  закреплён над облаком [M25.6], годы — облако чипов [M25.2], а «Без даты» и «Без превью» — отдельные
  фильтры [M25.4]. Фильтр по тегам накапливается по нескольким тегам [M25.1].
- «Текст на фото» ушёл из левой панели в «Настройки → Текст на фото», вместе с путём к `tesseract` и
  его версией [M25.13].
- Диалог настроек держит один размер во всех разделах: ни одна строка не расширяет панель, тело
  прокручивается, смещение прокрутки принадлежит разделу [M26.13].
- Вёрстка, которая выживает в узком окне: лента измеряется до отрисовки и переносится, ниже 670 px
  прокручивается вся левая панель, каждый диалог ужимается до окна и прокручивает тело [M26.6].
- Веса моделей скачивает сама программа по HTTPS (`ureq` + `rustls`), с согласием и проверкой
  `sha256`, поэтому модель можно получить на машине, где ничего не установлено [M24.1, M24.2].

### Исправлено

- dHash считается по кадру с EXIF-поворотом, поэтому две ложные группы дублей из портретных снимков
  исчезли (103 → 101 группа на корпусе) [M22.2].
- Эвристика OCR предлагала 203 кандидата вместо 357, пока модель CLIP ни разу не была выбрана:
  ветка по тегам искала словарь по пустому id модели [M23.6].
- Верхняя полоса в Windows вырастала до 42 px после строки прогресса фонового прохода; теперь это
  32 логических px при любом масштабе [M26.4].
- Диалог настроек расширялся с 794 до 966 px в «Тегах», где ряд действий словаря просил 716 px
  внутри колонки 520 px [M26.13].
- Превью плитки заполняет кадр 4:3 центральной обрезкой вместо полей, а длинное имя файла режется под
  оставшееся место, поэтому правая панель держит свои 280 px и сетка больше не прыгает при выборе
  фото [M22.15, M22.25].

### Удалено

- `scripts/fetch-model.sh`: загрузка модели — дело самой программы, а приложение, которое работает на
  Windows, не возит с собой shell-скрипт [M24.1].
